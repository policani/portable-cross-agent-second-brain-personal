# _inbox — drop raw material here

Drop anything you want the knowledge base to learn from but haven't shaped yet:
pasted notes, exports, transcripts, clippings.

Run the **ingest** skill to turn items here into notes — in this Personal
edition, ingest writes them **directly** into `knowledge-base/` (no approval
queue, because you're the only user), and you edit or prune in place. After an
item is ingested, delete it (or keep it elsewhere as a source of truth).

Don't drop genuinely sensitive material (credentials, personal/legal/medical)
here casually — label it or keep it out.
